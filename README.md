# Система формирования списка покупок

## Назначение

Веб-приложение и консольная программа для составления списка покупок.

## Целевая аудитория

Люди, которые заранее собирают список покупок.

## Предметная область

Товар хранит название и количество. Пользователь задаёт позицию списка
на дату. На одну дату у товара может быть только одна активная позиция.
Вычеркнутая позиция дату не занимает.

## Основные сущности

- Товар: название и количество
- Пользователь: имя и электронная почта
- Позиция списка: товар, пользователь, дата и признак вычёркивания

## Основные функции

- просмотр товаров и карточки товара;
- просмотр списка покупок и карточки позиции;
- консольные операции добавления и вычёркивания.

## Запуск консольного приложения

```
python main.py
```

## Запуск веб-приложения

```
pip install -r requirements.txt
python manage.py check
python manage.py runserver
```

Страницы: `/`, `/products/`, `/products/<id>/`, `/purchases/`,
`/purchases/<id>/`.

Данные веб-страниц читаются из JSON-файлов каталога `data/`
и выводятся шаблонами Django. Классы предметной области находятся
в пакете `models/`.

## Проверки

