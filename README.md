# Система формирования списка покупок

## Назначение

Приложение помогает решить, можно ли добавить товар в список покупок.

## Целевая аудитория

Люди, которые заранее собирают список покупок.

## Предметная область

У товара есть название и количество. Покупка планируется на дату.
Товар добавляют в список, если он доступен и количество больше нуля.

## Основные сущности

- Товар
- Позиция списка
- Пользователь

## Основные функции

- показать статус товара;
- преобразовать количество в текст;
- проверить, можно ли добавить товар в список.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
