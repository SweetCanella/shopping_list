# Система формирования списка покупок

## Назначение

Консольное приложение для составления списка покупок.
Товары, пользователи и позиции списка описаны классами.

## Целевая аудитория

Люди, которые заранее собирают список покупок.

## Предметная область

Товар хранит название и количество. Пользователь задаёт позицию списка
на дату. На одну дату у товара может быть только одна активная позиция.
Вычеркнутая позиция дату не занимает.

## Основные сущности

- Товар: название и количество
- Пользователь: имя и электронная почта
- Позиция списка: товар, пользователь, дата и признак вычёркивания

## Основные функции

- просмотр и поиск товаров;
- проверка количества;
- проверка, свободен ли товар на дату;
- добавление товара в список;
- вычёркивание позиции;
- просмотр списка покупок.

## Структура проекта

- main.py — точка запуска;
- models/ — классы предметной области;
- storage.py — сохранение и загрузка JSON;
- utils.py — вспомогательные функции;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты.

## Запуск программы

```
pip install -r requirements.txt
python main.py
```

Дата вводится в формате ДД.ММ.ГГГГ.

## Запуск тестов

```
pytest -v
```
