# Система формирования списка покупок

## Назначение

Консольное приложение для составления списка покупок:
учёт товаров и позиций на выбранную дату.

## Целевая аудитория

Люди, которые заранее собирают список покупок.

## Предметная область

Товар хранит название и количество. Позиция списка связывает товар
с датой. На одну дату товар добавляется только один раз.

## Основные сущности

- Товар
- Позиция списка

## Основные функции

- просмотр и поиск товаров;
- проверка количества;
- проверка, свободен ли товар на дату;
- добавление товара в список;
- удаление позиции;
- просмотр списка покупок.

## Структура проекта

- main.py — точка запуска;
- products.py — работа с товарами;
- purchases.py — работа с позициями списка;
- storage.py — сохранение и загрузка данных;
- utils.py — вспомогательные функции;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты.

## Требования

- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:

```
pip install -r requirements.txt
```

## Запуск программы

```
python main.py
```

Дата вводится в формате ДД.ММ.ГГГГ.

## Запуск тестов

```
pytest
```

## Проверка качества кода

```
flake8
```
